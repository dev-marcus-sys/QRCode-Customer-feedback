## 用户需求

将 QRCode 客戶意見反饋系統（F-001~F-010 可运行骨架）打包，交付到测试环境使用。

## 产品概述

产出一份「可部署文件包」+「手动逐步部署说明」，由目标测试机现场完成依赖安装与前端构建并启动运行；本次不实际执行部署动作，也不引入 Docker / CI/CD。

## 核心特性

- 生成干净的部署压缩包：保留 `backend/` 与 `frontend/` 同层结构（后端据此托管前端 `dist`），排除 `node_modules`、`frontend/dist`、`backend/data`、`*.log`、`.git` 及真实 `.env`，但包含 `.env.example`、锁文件与文档。
- 提供测试环境手动部署说明：目标机工具链准备（Node 20 + 原生编译工具）、解压、配置 `.env`、安装依赖、前端 `npm run build`、启动后端、验证清单与常见问题。
- 沿用 SQLite（`DB_PATH` 文件，零外部依赖）；后端首次启动自动建表、写入种子数据并托管前端静态资源（现有模式 B 单进程）。

## 技术栈与现状

- 后端：Node.js 20 + Express 4 + better-sqlite3（原生模块，目标机 `npm install` 时需编译）。
- 前端：React 18 + TypeScript + Vite 5；`npm run build` 产出 `frontend/dist`。
- 关键机制：`backend/src/app.js` 第 24、65–74 行——当 `frontend/dist/index.html` 存在时，后端以 `express.static` 托管并附 SPA fallback，实现单进程同时服务 API 与 UI（README 模式 B）。因此部署包必须保持 `backend/` 与 `frontend/` 为同级目录。
- `backend/src/db/connection.js`：`initDatabase()` 会自动 `mkdir` 数据目录、执行 `schema.sql`、空库时 `seed()` 并 `ensureDefaults()`，故目标机只需 `npm start` 即自动建库+种子。
- 两处均自带 `package-lock.json`，目标机可用 `npm ci` 可复现安装。

## 实现方案

采用「源码包 + 手册」策略：用一个 PowerShell 脚本复制出干净目录并压缩为部署包；另写一份繁体中文部署手册，让测试人员在目标机按步骤完成 `npm ci` → 前端 build → `npm start`。不引入容器/CI，符合「只产部署包、手动即可」的约束。

关键技术决策：

- **目标机现场 build**：按澄清结果，前端与 better-sqlite3 均在目标机编译，部署包只含源码与锁文件，避免携带平台相关的 `node_modules`/`dist`。
- **保留兄弟目录结构**：压缩包根下必须同时含 `backend/` 与 `frontend/`，否则 `path.resolve(__dirname,'../../frontend/dist')` 解析错误，后端无法托管前端。
- **排除真实密钥**：`.env` 不进包，仅保留 `.env.example`，由测试机复制后修改 `JWT_SECRET`/`PORT`/`DB_PATH`。
- **不接 PM2/systemd**：测试环境用简单前台/后台启动即可，降低复杂度。

## 实现要点（防回归）

- 打包脚本排除项需精确覆盖：`**/node_modules`、`**/dist`、`backend/data`、`**/*.log`、`.git`、`**/.env`；显式包含 `backend/.env.example`、`*/package-lock.json`、`db/schema.sql`、`db/seed.js`、`db/ensureDefaults`、`docs/`、`*.md`。
- 部署手册须强调：Windows 目标机需安装 Visual Studio Build Tools + Python 3（better-sqlite3 编译）；Linux 需 `build-essential` + `python3`。
- 验证清单：① `GET /api/v1/health` 返回 `ok`；② 浏览器开 `http://<host>:<PORT>/?estate=CHNG` 见公众表单；③ `/admin/login` 以 `admin/Admin@2026` 登录见个案列表。
- 手册注明回滚方式：停止进程后删除 `backend/data/*.sqlite*` 即可重建种子库。
