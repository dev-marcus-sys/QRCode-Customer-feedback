## 產品概述

QRCode 客戶意見反饋系統（QR Code 客戶意見反饋子系統）：面向物業管理 4 個試點屋苑（灣景中心 / 攸壆路 / 頌雅苑 / 大夫第）的住戶意見收集與個案處理系統。住戶掃描屋苑張貼的 QR Code 進入系統自建線上表單提交意見，系統自動建立個案，後台完成分派、跟進、完結、滿意度調查與數據分析的全流程閉環管理。
本規格書範圍**僅限 QR Code 管道**（公眾表單 + 個案管理後台），不包含客服熱線、現場、APP、電郵等其他管道（保留管道欄位與擴展點），並於附錄說明與《多管道客戶意見反饋管理系統》的從屬關係及未來整合方式。

## 核心功能

- **公眾意見表單**：掃碼自動帶入屋苑、10 個欄位驗證（稱謂/姓名/日期時間/電郵/電話/地址/意見種類多選/意見內容≤1000字/是否接受調查）、繁中英雙語、手機相容、10 分鐘防重複提交、成功提示頁及含個案編號之確認電郵。
- **個案自動建立與編號**：提交即時自動建案、依「公司/業務/屋苑/年月日/序號」規則生成唯一編號、初始狀態待分派並自動計算 SLA 到期時間。
- **個案管理後台**：列表多維篩選與 Excel/CSV 匯出、個案詳情、依屋苑與意見種類自動建議分派、轉派（需原因並通知雙方）、時間軸跟進記錄、7 態狀態機、完結申請與主管審核/駁回、主管授權重開、二次投訴識別與關聯。
- **到期提醒與預警**：依事件類型（特急 5 分鐘/緊急 30 分鐘/一般 2 小時/4 小時）自動預警、逾期升級通知本人及主管、7 天關閉期限提醒、儀表板標紅。
- **滿意度調查**：個案關閉後自動發送問卷（整體/回應速度/態度/解決程度 1-5 分 + 開放意見）、14 天有效期、低分（≤2 分）自動告警。
- **儀表板與 KPI**：12 項 KPI 自動計算（結案時效、及時率、7 天達標率、滿意度等）、柱狀/餅圖/折線/儀表盤、多維度篩選與鑽取、每週一自動生成週報。
- **參數配置與權限**：RBAC 6 種角色、SLA 時限、屋苑名單、意見分類、編號規則、表單樣式、調查有效期等可視化配置；操作審計日誌。
- **開發落地章節**：資料庫 Schema 與 MySQL 相容 DDL、REST API 定義（端點/參數/回應/錯誤碼）、頁面結構與 ASCII 線框、非功能需求與驗收標準。
